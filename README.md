# Sustainability Innovation Challenge

A simple, session-only React/Vite classroom activity based on the Northstar Components scenario pack.

## Features
- 5 multiple-choice management scenarios across five stages
- Immediate, constructive feedback for every option
- Scores calculated locally in the browser
- Final score and performance summary
- No login, backend, database, analytics, cookies, or response collection
- Refreshing or closing the tab resets the activity

## Run locally

```bash
npm install
npm run dev
```

## Privacy
All answers and scores remain in React state in the student's browser tab. The app does not send responses anywhere.
